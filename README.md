# Introduction to Machine Learning for Engineers (IMLE) - Course Work

This repository contains my coursework, tutorials, exercises, and computational materials for the **Introduction to Machine Learning for Engineers (IMLE)** course during the **5th Semester** of my B.Tech in Computer Science and Engineering at **Indian Institute of Technology Bhubaneswar (IIT BBS)**.

## 📚 About the Course

The course focuses on fundamental concepts of Machine Learning, including mathematical foundations, computational techniques, and practical implementation of ML algorithms using Python.

The repository contains hands-on exercises and learning materials completed as part of the course.

## 🛠️ Technologies Used

- Jupyter Notebook / Google Colab
- NumPy
- Pandas
- Matplotlib
- Scikit-learn
- Other Python-based ML libraries
